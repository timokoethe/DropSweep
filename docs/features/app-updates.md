# App Updates

## Purpose

Keep DropSweep current with released fixes and improvements.

## User Story

As a user, I want DropSweep to check for updates so that I can install the latest available version.

## Acceptance Criteria

- DropSweep automatically checks for available updates.
- The menu provides a manual Check for Updates action.
- The action is disabled while an update check is unavailable.
